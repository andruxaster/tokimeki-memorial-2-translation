# Перевод Tokimeki Memorial 2 (PS1) на русский — инструкция для переводчика

Игра — школьный дейт-сим. Герой (игрок) учится в старшей школе Хибикино и общается с девушками и друзьями.
Тон: живой, разговорный русский, как в хорошей фанатской локализации аниме. Сохраняйте характер персонажей.

## Формат входа (batch_XX.txt)
```
### SCENE n
  [говорит: 白雪]          <- кто говорит дальше (метка из скрипта)
123	26	японская строка      <- id, лимит в байтах, текст
ctx	-	японская строка	=> перевод   <- только контекст (уже переведено или переводится в другом пакете), НЕ переводить.
                                        Если после => есть русский вариант — это готовый перевод с диска 2: держитесь той же терминологии и тона.
```
Одна запись — одна строка в окне диалога. Сообщение (реплика) обычно 1–3 строки подряд: переводите
реплику целиком, но раскладывайте её по тем же строкам (каждая строка — отдельный id).
Если id встречается в пакете несколько раз — переведите один раз.

## Формат выхода (out_XX.tsv)
UTF-8, по строке на id: `id<TAB>перевод`. Только строки с числовым id из ВАШЕГО пакета.

## Ограничение длины (важно!)
Каждые 2 русские буквы/пробела/знака из набора ниже занимают 2 байта (одну клетку шрифта),
т.е. лимит в байтах ≈ максимальное число русских символов.
- Узкие символы (по 1 «букве»): а-я, А-Я, ё, Ё, пробел, . , ! ? - : ; … " ( ) « » '
- Всё остальное (цифры, 「」『』, ～, ♪, японские знаки) занимает целую клетку = 2 «буквы».
- Токены вида {21}, {1e}, {33:22} — 1–2 байта.
Проверяйте себя: `python3 tr/check.py tr/out_XX.tsv` — скрипт покажет строки, которые не влезают.
Все строки должны пройти проверку. Если не влезает — перефразируйте короче (не обрезайте смысл грубо).

## Токены {xx}
Это подстановки, их надо сохранить ВСЕ и в том же порядке (скрипт проверки это проверяет):
- {1d} фамилия игрока, {1e} имя игрока, {1f} прозвище игрока;
- {10}…{1c}, {20}…{2d} — обращение к игроку или имя персонажа (зависит от сцены: например, в
  «{21}を待とう）» это имя девушки, которую ждём). Подставленное слово стоит в именительном падеже,
  поэтому стройте фразу так, чтобы токен не требовал склонения: «{21}… где же она?», «Жду: {21}».
- {2e:xx}, {2f:xx}, {3x:xx} — служебные коды (пауза, звук), оставить на месте.

## Оформление
- Мысли героя в японском заканчиваются на ）(начинаются со （ в предыдущей строке) — сохраняйте скобки: ( … ) узкие.
- Варианты ответа в 『』 — оставляйте 『』 (они полноширинные, по 2 байта каждая) или, если тесно, без них нельзя — оставьте.
- Многоточие «……» → «…». Тильда «～» в конце слов (растянутое) → передайте буквами («давай~» нельзя: ~ нет в наборе) — «Даваа-ай!».
- Цифры по возможности словами (цифры дорогие).
- Японские суффиксы (-кун, -сан, -тян) не используйте, кроме устойчивых случаев; «先輩» → «сэмпай» допустимо в речи младших.
- Не используйте символы вне набора: — – “ ” „ № и т.п. (тире пишите «-»).

## Глоссарий
Хиномото Хикари (陽ノ下光) — подруга детства героя. Сираюки Михо (白雪美帆), её сестра-близнец Сираюки Махо (白雪真帆).
Сакура Каэдэко (佐倉楓子). Котобуки Миюки (寿美幸). Акаи Хомура (赤井ほむら). Яэ Каори (八重花桜梨).
Итимондзи Аканэ (一文字茜). Минадзуки Котоко (水無月琴子). Идзюин Мэй (伊集院メイ) — заносчивая богачка, говорит «...のだ»,
зовёт всех «貴様» (→ «ты, простолюдин»/«ты»). Сакаки Такуми (坂城匠) — лучший друг героя. Хокари Дзюнъитиро (穂刈純一郎) —
друг-«спортсмен». Кудансита Майка (九段下舞佳). Нодзаки Сумирэ (野咲すみれ). Асо Касуми (麻生華澄) — учительница, бывшая соседка.
Школа Хибикино (ひびきの高校). Город Хибикино. Мост Идзюин (伊集院大橋). Центральный парк (中央公園). Станция Хибикино (ひびきの駅).
Площадь у станции (駅前広場). Храм (神社). おやぢ — «батя» (так называют владельца лавки). 番長 — «главарь» (школьный хулиган).
マルハゲドン — фильм «Марухагеддон». Клубы: 吹奏楽部 духовой оркестр, 陸上部 лёгкая атлетика, 野球部 бейсбол,
サッカー部 футбол, テニス部 теннис, バスケ部 баскетбол, 美術部 изостудия, 茶道部 чайная церемония, 演劇部 театральный кружок.
Параметры героя: 体調 здоровье, 文系 гуманит., 理系 точные, 芸術 искусство, 運動 спорт, 雑学 эрудиция, 容姿 внешность,
根性 стойкость, ストレス стресс. EVS — система, называющая героя по имени.
