# Перевод «простых» строк Tokimeki Memorial 2 (мини-игры, концовки, песни, альбом, PocketStation)

Сначала прочитайте основной глоссарий и правила тона: `tr/GUIDE.md` (раздел «Глоссарий», «Оформление», допустимые символы). Ниже — отличия формата.

## Вход (`plain_XX.txt`)
```
### GROUP disc1 74dcb2c                  <- группа соседних строк (один экран / одна таблица)
123	46	46	текст                         <- id, общий лимит в байтах, лимиты строк, японский текст
124	91	26/24/22	строка1|строка2|строка3   <- '|' = перенос строки; лимит для каждой строки через '/'
```
Строки одной группы идут в том порядке, в котором лежат в игре. Часто одна фраза или абзац
разрезан на несколько записей подряд (например, описание тактики в мини-игре «сбей шест» по 23 знака
в строке) — переводите абзац целиком и раскладывайте по тем же записям.

## Выход (`plainout_XX.tsv`)
UTF-8, по строке на id: `id<TAB>перевод`. Переносы — тем же символом `|`, **количество строк
должно совпадать** с японским. Если строка начинается с пробела после `|` (`| お魚…`) — оставьте этот пробел.

Если строку переводить нельзя или не нужно — напишите `=` вместо перевода (оригинал останется). Так помечайте:
- таблицы символов, наборы каны, коды;
- произношения/чтения имён каной (для синтеза речи);
- непонятный мусор.

## Длина
Как и в основном переводе: каждая русская буква/пробел/узкий знак ≈ 1 байт, цифры и японские знаки — 2 байта.
Лимит каждой строки — число после табуляции (через `/` для многострочных), общий лимит — второе поле.
Проверка: `python3 tr/check_plain.py tr/plainout_XX.tsv` — все строки должны пройти.

## Особенности
- **Имена реальных людей в титрах** — транслитерируйте по Поливанову (Ватанабэ Мисато), должности переводите.
- **Названия эпизодов альбома** («二人きりの聖夜» и т.п.) — короткие русские заголовки.
- **Тексты песен** — перевод по смыслу, можно без рифмы, укладываясь в лимит строки.
- **Концовки** («…は、ファッションモデルを目指すことになった» и т.п.) — связный рассказ, фразы разрезаны на строки-записи.
- **Имена героинь в списках** (寿　　美幸 и т.п.): если полное имя не влезает, оставьте имя («Миюки»).
- Обрывки вроде «さん», «ちゃん», «ですか？» — это части, которые игра склеивает с именем; переводите так,
  чтобы склейка читалась: «さん» → «» нельзя (пустую строку нельзя) — ставьте `=` если перевод невозможен, иначе разумный вариант.
