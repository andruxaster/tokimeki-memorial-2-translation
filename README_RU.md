# Tokimeki Memorial 2 (PS1) — русский и английский фанатский перевод

Перевод **Tokimeki Memorial 2** (Konami, 1999), издание Konami The Best, 5 дисков. Обе версии —
готовые патчи PPF 3.0, без игровых данных: нужны ваши собственные образы дисков.

- `patches/ru/TM2_RU_disc1..5.ppf` — русская версия;
- `patches/en/TM2_EN_disc1..5.ppf` — английская версия.

Патч N накладывается на диск N (BIN/CUE, MODE2/2352). Контрольные суммы исходных образов — в
`README.md`. Подойдёт любая программа для PPF 3.0 (PPF-O-Matic, ApplyPPF).

Переведено всё: сценарий всех пяти дисков (36 687 уникальных строк), имена говорящих, ввод имени
кириллицей/латиницей, календарь, интерфейс, карта памяти, опции, графические кнопки, сообщения
исполняемого файла, экран EVS, мини-игры, концовки, альбом, PocketStation.

Подробная история русской версии — `CHANGELOG_RU.md`. Сборка из исходников и формат таблиц —
`README.md` (раздел Building from source), правила перевода — `tr/GUIDE.md` (рус.) и
`tr_en/GUIDE_EN.md` (англ.).

Перевод сделан с помощью ИИ и требует вычитки; исправления присылайте через issues / pull requests.
